# 常明城人物资产与组合规则

本文档记录生产页面实际使用的视觉口径。旧的“透明 PNG 抠图协议”已废弃：纸色背景与肤色接近，自动抠图会伤到脸和手，在深色页面也会出现脏边。

## 生产资产

- `v9/heroes/`：10 张单人完整场景。甲、乙、丙、丁、戊、己、庚、辛、壬、癸各用一张，阳火与阴火不共图。
- `v10/relations/`：10 人两两组合的 45 张独立故事图，数量为 `C(10,2)=45`。关系方向由文案说明，同一对人不因观看方向再复制一张图。
- `v10/groups/`：三人以上共同事件图。当前生产样板为甲、乙、癸修桥；三个人必须在同一事件里承担不同动作，不能用三张立绘并排冒充同框。
- `v9/relations/`：早期按五行关系生成的样板和三人构图，仅作编辑参考，不是 45 对关系的生产真值源。
- `v8/full-body/*.png` 与 `v8/portraits/*.png`：废弃的自动抠图试验，不得再接回页面。

## 页面组合规则

- 单人卡和人物入口使用完整场景图，通过每个人的 `heroFocus` 控制 `object-position`，不拉伸，不把全景硬塞进窄卡。
- 任意一人都能设为常用主题人物；这只改默认展示，不改日主和命盘计算。
- “你的八个命盘位置”是运行时构图：四个天干直接映射人物，四个地支用主气藏干映射人物。同一人可以在不同位置重复出现，所以它是“八个位置”，不保证是八个不同人。
- 八位置群像不穷举为 64 张固定素材；由页面按实际命盘动态组合。固定穷举的只有 45 对双人关系图。

## 文案边界

- 用户只看到完整的人物小故事和关系方向，不看到“创作题眼”、审稿标签、规则数量或资产状态。
- `character-manifest.js` 里的 `scar` / `highlight` / `ongoing` 是人物设定底稿，当前不渲染到用户界面。
- 专业关系名放在白话之后，并明确说明只表示作用方向，不作吉凶判断。

## 视觉验收

- 女性人物不得因生成漂移变成无设定依据的白发。
- 关系图不只是两人并排；应轮换使用背靠背合作、正面对抗、一人拉住另一人、共同操作器物等能读出作用方向的动作。
- 发布前生成 10 张单人与 45 张关系图的 contact sheet，检查人物发色、重复构图和焦点。
