# 常明城人物系统 v10

更新时间：2026-08-14

## 用户界面规则

- 一张命盘的八个字对应八个人物位置：年干、年支、月干、月支、日干、日支、时干、时支。
- 四个天干直接对应十干人物；四个地支取排盘引擎返回的第一主气藏干，再对应人物。
- 日干是“你”。其余七个位置显示相对日干的同类、我生、生我、我制、制我关系；天干合、冲作为附加效果。
- 同一人物在不同位置重复出现时不去重，因为年、月、日、时的位置意义不同。
- 五行相对较少只能推出一个元素，不能推出该元素里的某一个阴干或阳干。因此入口分别展示两个人物，例如火少时丙、丁各一张独立人物图。
- 用户可把任意一个人物设为常用主题；这不会改变日干和命盘计算。

## 穷举结果

使用站内同版本 `lunar-javascript 1.7.7`，枚举 1900-01-01 至 2099-12-31、每两小时一个时辰，共 876,588 个合法时刻：

- 保留八个位置时，有 358,470 种人物阵容。
- 忽略位置、只看人物多重集合时，有 18,376 种组合。
- 同一个人物最多出现 6 次。
- 同一个五行最多出现 8 次；例如 `壬子 壬子 癸亥 壬子` 映射后八个位置全属水，由壬、癸组成。

因此八人群像不能按 64 张静态图穷举。前台采用实时八人阵：10 套角色视觉组件、八个固定位置、关系动效和按需关系故事图。

## 两两关系资产

十个人两两组合共有 `C(10,2) = 45` 对唯一关系；从 A 看 B 和从 B 看 A 共用一个事件场景，但关系称谓按观看方向计算，共 90 个观看方向。

v10 已完成并人工视觉复核全部 45 对专属图。每对只有一个共同事件场景、一个独立文件和一个唯一 pair key；不存在两对共用同一路径。图片统一为 `1672×941` 的 16:9 WebP，网页按容器裁剪，不再抠透明 PNG。

资产目录：`www/img/ten-archetypes/human/v10/relations/`。文件名使用固定干序，例如 `bing-ding-v1.webp`、`xin-gui-v1.webp`。旧 v9 资产保留用于回退，但 v10 关系页不再调用旧的三人元素组图。

验收要点：

- 两位人物均以 `v8/full-body` 定稿为 identity reference，禁止白发漂移、性别漂移和大火小火共用人物图。
- 每张图必须有具体共同动作，而不是换人套同一站姿；画面细节集中在脸、手和事件焦点，背景降低精细度。
- 全量检查必须确认 45 个 key、45 个文件、45 个不同路径、90 个方向视图均存在。

## 面向用户与内部字段

- 前台显示 `readerTitle` 与 `readerStory`：一段完整、第二人称、可代入的小故事。
- `scar`、`highlight`、`ongoing` 是早期编剧素材，暂留在数据与 Git 历史中，不再直接展示给用户。
- 用户文案不使用“高光”“伤疤”“现在还没有答案”等内部栏目名，也不把创作意境字面化为固定世界观设定。
