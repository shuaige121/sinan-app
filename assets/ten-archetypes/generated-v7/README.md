## 资产层级

- `chroma/`：每人一张三姿势 magenta 源图，保留为可追溯母版。
- `transparent/`：去底后的完整三姿势图。
- `../../../www/img/ten-archetypes/human/v7/poses/`：App 使用的单姿势透明 PNG。
- `../../../www/img/ten-archetypes/human/v7/{slug}.png`：身份主图，与 `identity` 姿势一致。
- `../comics/v7/`：由定稿身份图作为 reference 生成的无字漫画原图。
- `../ensemble/v7/changming-ensemble-v1.png`：十人身份拼板与衡枢背景共同作为 reference 生成的合影原图。

三种姿势固定语义：

- `identity`：八字结果页角色觉醒。
- `story`：人物小传与章节入口。
- `open`：关系图、群像拼板、后续章节的开放动作。

全部单姿势图均为 `512×1024 RGBA PNG`，四角透明；角色按真实 alpha bounding box 重排，发梢、手臂与衣摆未被裁断。

## 十人合影

合影使用十人身份拼板锁定全员身份，再与衡枢城市背景共同图生图。画面包含且只包含十名角色；中心是石、水道、金属校准环、木构与透光片共同组成的无属性衡枢，五色短暂重合成白，不使用炉火作为中心。十人都处于协作动作，没有 C 位、胜利姿势或大结局。

## 后续生成协议

1. 以同一人物的 `identity`、`story`、`open` 三张 PNG 同时作为 identity reference。
2. 锁定脸、发型、三头身比例、服装结构和主色，只改变叙事动作、景别与场景。
3. 漫画必须来自人物志中的已写事件；不先造场面再硬贴五行符号。
4. 不写胜利、和解或永久完成；末格保留正在发生的动作。
5. 图中不生成标题、对白和 UI 文字，文字全部留给产品层。

## App 接入

`www/js/character-manifest.js` 保存角色身份、姿势与可选漫画资产；`www/js/app.js` 负责按日主显示身份图、人物志动作和漫画。角色没有漫画时不渲染漫画区，不会出现空占位。
