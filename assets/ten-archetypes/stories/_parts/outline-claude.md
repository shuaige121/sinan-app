# 《常明城》全书写作大纲 · Claude 基线（确定性骨架）

这一份只放**不能由任何写手自行发挥的部分**。Codex 与 Fable 的大纲负责 beat sheet、反同构与编排；
本文件负责钉死事实层，冲突时以本文件为准。

## 0. 命名规则

正文一律用角色名，天干只出现在标题行与内部标签：

甲=广莫、乙=南枝、丙=忘归、丁=西窗、戊=不周、己=沃野、庚=运斤、辛=瑾瑜、壬=既望、癸=雪泥。

人称一律用名字，必要时用中性的「他」。禁止用「她」制造性别映射；禁止再用「它」指代人物（V4 起十人是人形角色，母本 V2 正文里的「它」是 V1 遗留，本次一并纠正）。

## 2. 五幕交接链（实物，不得改动）

序章 白光分色 → 十人各自加力 → 五色分得更远 → 决定走完五环，从木部起步

1. 第一幕 木部 → 交出：切下的一段活根 + 一批旧材 → 火部（林线明显变薄）
2. 第二幕 火部 → 交出：按西窗节拍烧出的灰 → 土部（火部的灯少了一大半，城比从前暗）
3. 第三幕 土部 → 交出：沉降压实后露出的矿脉 + 记重册 → 金部（山从此少一部分）
4. 第四幕 金部 → 交出：切通的旧渠 + 卷刃的凿具 + 磨断的细线 → 水部（金部这一季拿不出新器）
5. 第五幕 水部 → 交出：大水与细雨同时抵达木部（外河沿线因放慢而吃亏）
6. 终章 → 五色重合一个呼吸，随即边缘浮出极细青色，玄光慢了半拍

每幕开头必须写清上一幕交来的东西已到；每幕结尾必须写清交出者因此少了什么。

## 5. 十人锚点（伤疤，来自设计规范 2.1，不得漂移、不得被高光治愈）

- 广莫：不再给树取名
- 南枝：没人问他想要什么
- 忘归：没有只属于他的人
- 西窗：期待黑夜并为此羞耻
- 不周：堤也挡住了想离开的人
- 沃野：分不清什么该拔掉
- 运斤：从未因果断被感谢
- 瑾瑜：害怕被使用和磨损
- 既望：外面也一样
- 雪泥：怀疑自己是否在场过

## 6. 红线（母本第 9 节，违反即作废）

- 不写永久平衡、使命完成、从此不再分色；任何一篇都不能以大团圆定格收尾。
- 高光只是一次关键选择，不治愈伤疤；写完高光必须让读者看见此人下一次仍可能犯回原来的错。
- 关系不锁死成恋人/朋友/敌人；合不是恋爱，冲不是正邪，不承诺和解。
- 阴阳不是性别。
- 生必须写出给予者的实际消耗；制必须写出被制方获得的形状 + 设限方承担的判断责任。
- 衡枢不是第六元素、不是能源、不是神殿、不是王座；常明白只是证据。
- 无反派、无外敌、无天然领袖、无最终能源。冲突全部来自节拍与过量。
- 禁用词：命硬、克夫、破财、凶、煞、劫难、犯太岁；用户层说「相制」不说「相克」。

## 7. 文风硬约束

- 禁止收束句：从此以后 / 终于明白 / 这一刻他懂了 / 原来……才是…… / 而这，正是……
- 禁止 AI 腔开头：在这个……的世界里 / 当……的时候 / 有人说……
- 「第一次」每篇最多一次（母本自身已用滥）。
- 不写全城欢呼，不写有人发表演说总结道理，不加作者按语。
- 不解释五行原理，让动作承担关系方向；不贴性格标签，用行为写出来。
